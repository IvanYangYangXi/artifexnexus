### P0 修复：SkillList 运行时 TypeError（software 序列化为字符串）

**错误**：`(skill.software || []).map is not a function` @ `SkillList.tsx:283`

**根因**：`_rpc_helpers.py` 中 `_entry_to_dict()` 调用 `software_value(manifest.software)`，该函数签名为 `Software | str -> str`，返回的是单个字符串而非 `DCCEntry[]` 数组。前端期望数组却收到字符串，`.map()` 调用失败。

**修复**：
- `_rpc_helpers.py`：移除 `software_value` 导入；新增 `_serialize_software()` 函数，将 `List[DCCEntry]` 序列化为 `[{dcc, minVersion, maxVersion}]` 数组；`_entry_to_dict()` 改用新函数
- `SkillList.tsx`：添加前端防御性检查 `Array.isArray(skill.software)` 替代 `(skill.software || [])`，防止非数组值传入 `.map()`

### P0 修复：修改 DCC 软件版本报错 'dict' object has no attribute 'dcc'

**错误**：前端编辑 tool 的 software 版本 → sidecar 报 `'dict' object has no attribute 'dcc' (code: -32000)`

**根因**：前端 JSON-RPC 传入的 `software` 是 dict 列表 `[{dcc, minVersion, maxVersion}]`，但 `NexusToolData` 是 dataclass（非 Pydantic），没有 validator 自动转换。dict 直接存入 `td.software`，后续 `_nt_data_to_dict` / `_handle_nexus_tool_run` 访问 `e.dcc` 时失败。

**修复**（`installer.py`）：
- 新增 `_normalize_software()` 函数，将 `Dict | DCCEntry | str` 统一转为 `List[DCCEntry]`
- `create_nexus_tool`：传入的 software → `_normalize_software()` → DCCEntry 列表
- `update_nexus_tool`：在 `setattr(td, key, value)` 之前调用 `_normalize_software()`
- Scanner 已有正确转换逻辑（从磁盘 manifest.json 读取），不受影响

### 修复：卡片 active 高亮完全不显示（inline style 替代 Tailwind class）

**根因**：`tailwind-merge` v2.5.4（Tailwind v3 设计）+ Tailwind v4 的 `!important` 修饰符存在兼容性问题。
`!border-primary/40` 的 `!` 前缀导致 twMerge 的冲突解析逻辑失效，active 状态的 class 被丢弃或未覆盖基础样式，
表现为底色和外框高亮都不显示，只有 hover 效果工作。

**修复**（`ItemCard.tsx`）：
- `ItemCardView`：移除 `active && "!border-primary/40 bg-primary/[0.08]"` class，改用 `style` prop 直接设置 `borderColor` + `backgroundColor`
- `ItemListRow`：移除 `active && "border-l-2 border-l-primary/60 bg-primary/[0.06]"` class，改用 `style` prop 设置 `borderLeft` + `backgroundColor`
- inline style 完全绕开 Tailwind class 冲突机制，CSS 特异性最高，保证高亮始终可见

### 修复（第二次）：inline style 仍未生效 → 改用 data-active + CSS 规则

**问题**：inline style 方案仍然不显示高亮。用户反馈"高亮问题还是没有解决"。

**分析**：inline style 理论上 CSS 特异性最高，但如果 React 渲染时机或 DOM 更新有问题，仍可能不生效。改用更可调试的方式。

**修复**：
- `ItemCard.tsx`：移除 inline `style` prop，改用 `data-active={active ? "true" : undefined}` 属性；添加 `React.useEffect` console.debug 日志确认 `active` prop 传递
- `globals.css`：新增 `[data-active="true"]` CSS 规则，使用 `outline`（不占盒模型空间）+ `background-color`，用 `!important` 确保优先级
- `SkillList.tsx`：`doAction` 添加 console.debug 日志确认 `setActiveSkill(id)` 被调用；render 中匹配时打印日志
- `NexusToolList.tsx`：同理添加 console.debug 日志

**调试方法**：

## 偏好持久化升级（2026-05-20 下午 v2）

### 问题
localStorage 在 Tauri WebView 重启后可能丢失（调试模式/数据清理），用户设置不持久。

### 解决方案
创建 `packages/apps/web/src/lib/useUiPref.ts` hook：
- 初始值优先读 localStorage（快速，避免 RPC 延迟闪烁）
- mount 后异步读 `app.settings`（后端文件 `~/.artifexnexus/.openclaw/state/artifex/app-settings.json`）
- 若后端值不同则覆盖（文件 > localStorage），并回写 localStorage 同步
- setValue 同时写 localStorage（即时）+ 异步写 app.settings（持久化）
- 非 Tauri 环境（浏览器预览）静默降级为 localStorage-only

### 后端新增字段
`app_settings.py DEFAULT_SETTINGS`：`skillViewMode / toolViewMode / skillFavoritesOnly / toolFavoritesOnly`
`openclaw.ts AppSettings` 接口同步扩展。

### 调用方
- `SkillList`：`useUiPref<"card"|"list">("skillViewMode", "card")` / `useUiPref<boolean>("skillFavoritesOnly", false)`
- `NexusToolList`：同上，key 分别为 `toolViewMode` / `toolFavoritesOnly`
- 旧的 localStorage helpers (VIEW_KEY/FAV_KEY/loadXXX/saveXXX) 全部删除

### 标签推荐修复
之前 `allTagSuggestions` 只从当前 entry 自身 tags 收集，推荐几乎为空。
修复：`SkillDetailPanel` / `ToolDetailPanel` 主组件 mount 时异步做一次 list(limit=500)，聚合所有 item.tags，通过 `globalTagSuggestions` prop 传给 InfoTab → TagEditor。

### tag收集不写后端
标签是 manifest 元数据（manifest.json），非用户偏好。后端不存储标签偏好——用户通过 TagEditor 编辑的标签调用 `skillUpdateManifest`/`nexusToolUpdate` 写入 manifest.json，`skills.json` 只存 enable/disable/pin/favorite。

### P0：Tool 收藏持久化失效 — `SkillConfig._load()` 未加载 `nexus_tools` key
**根因**：`skill_config.py` 的 `_load()` 方法只加载 `("disabled", "pinned", "favorites")` 三个 key，没有加载 `"nexus_tools"`。
- 每次 sidecar 重启 → `SkillConfig.__init__` → `_load()` 跳过 `nexus_tools` → `_data` 无工具收藏数据
- 任何 `_save()` 操作（如技能 pin/favorite）会把缺少 `nexus_tools` 的 `_data` 写回文件，彻底覆盖之前的工具收藏

**修复**：`_load()` 的 key 列表增加 `"nexus_tools"`：`for key in ("disabled", "pinned", "favorites", "nexus_tools")`

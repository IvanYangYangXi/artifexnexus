## Sidecar ImportError 修复（2026-05-16 21:18）

### 问题
sidecar 作为脚本运行时，相对导入 `from . import ...` 失败 → fallback 到绝对导入。
但 `skill_rpc.py` 和 `nexus_tool_rpc.py` 只有裸 `from ._rpc_helpers import ...`，无 fallback → 二次 ImportError 导致 sidecar 崩溃。

### 修复
- `skill_rpc.py:19` — 加 try/except ImportError → fallback `from _rpc_helpers`
- `nexus_tool_rpc.py:20` — 同上
- `nexus_tool_rpc.py:450` — `from .mcp_bridge` 也加 fallback
- 其他 7 个模块早已有相同 fallback 模式，无需修改

## UI 约定

### Select/下拉框规范
**必须使用设计令牌，禁止硬编码 `bg-white/[0.0x]`/`backdrop-blur`：**
```
rounded-md border border-input bg-input px-2 text-xs text-foreground 
focus:outline-none focus:ring-1 focus:ring-ring 
[&_option]:bg-card [&_option]:text-foreground
```
- `rounded-md`（6px）= 输入框圆角规范（design-language.md §5）
- `border-input` / `bg-input` = 输入框 L3 色（HSL 0 0% 12.2%）
- `focus:ring-ring` = 品牌蓝焦点环（213 78% 65%）
- **禁止** `appearance-none`（会隐藏原生下拉箭头）
- **禁止** 玻璃效果（`backdrop-blur`）用于输入控件，玻璃仅用于卡片/弹层（§3.5）

### Blender 触发器钩子
- 钩子注册入口：`blender_addon/__init__.py` 的 `register()`
- 钩子函数必须用 `@bpy.app.handlers.persistent` 装饰
- 使用 `*args` 签名兼容不同 Blender 版本
- 事件通知通过 `MCPServer.broadcast_trigger_event()` → `asyncio.run_coroutine_threadsafe`
- 前端的触发器横幅根据 DCCStatusContext 动态显示/隐藏

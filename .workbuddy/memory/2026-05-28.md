### publish 后仍 shows needs_publish 深度修复（2026-05-28）

**根因分析**:
installer.publish() 只更新 flat install dir (`~/.artifexnexus/.openclaw/workspace/skills/<name>/manifest.json`)
但 _skill_check_sync 比较 install_dir 和 hub entry.path（project source dir，如 `skills/official/<name>/`）。
当 skill 同时存在于两处时，project source dir 的 manifest.json 未更新 → compare_skill_dirs 检测到差异 → needs_publish 恒为 true。

**Fix 1 — installer.py publish()**:
- 写入 install dir manifest.json 后，同步更新 target_layer 源码目录的 manifest.json
- 通过 `self._layer_sources` 查找 target_layer 对应目录
- 用 `_source_skill_dir` 定位 skill，存在则更新其 manifest.json
- 所有异常均记录 warning 日志，不阻断成功返回
- 改进原有 silent fail（except pass）为 logger.warning

**Fix 2 — SkillDetailPanel.tsx 版本号不可编辑**:
- 移除 `<input>` 编辑框，改为 `<p>` 只读显示
- 保留 version state + versionValid（供保存逻辑用，始终为 true）
- TS 编译: 0 errors

## Sidecar 启动崩溃修复（2026-05-28 18:39）

### 问题
所有 RPC 调用返回 `写入 sidecar 失败: 管道正在被关闭。 (os error 232)`。
Sidecar stderr 显示：

```
[sidecar.boot] python entrypoint reached
Traceback: from . import agent_preset → ImportError: attempted relative import with no known parent package
  → except → import dcc_connections → dcc_connections.py:27: from . import mcp_bridge → ImportError
```

### 根因
`sidecar.py` 以 `python sidecar.py` 脚本模式执行（非 `python -m`），相对导入全部失败。
sidecar.py 本身有 dual-path try/except fallback，但 `dcc_connections.py:27` 的 `from . import mcp_bridge` **没有** fallback → 级联崩溃。

### 修复
`dcc_connections.py` 两处：
1. **第 27 行**（模块级）：`from . import mcp_bridge` → 加 try/except + fallback `import mcp_bridge`
2. **第 279 行**（函数体内 `_list_connections`）：`from . import _runtime` → 加 try/except + fallback `import _runtime`

其他模块均已存在 dual-import 保护，仅 dcc_connections.py 遗漏。

## 01:04 — MCP 连接页：缺少 Maya/Max + UE 状态错误

**问题 A**：日历 MCP 连接页只显示 Blender 和 UE，缺少 Maya 和 3ds Max

**问题 B**：UE 显示"等待连接"而非"未启动"（两个软件都没启动，Blender 正确显示"未启动"）

**根因分析**：

1. `sidecar.py` `_handle_mcp_servers_list` 中 DCC 名称匹配用 `startswith`：
   - `"unreal-editor".startswith("unreal-engine")` → False → dcc=None
   - `"max-primary".startswith("3ds-max")` → False → dcc=None
   - dcc=None → 跳过所有状态检测 → error=None → 前端显示"等待连接"

2. `dcc_installer.py` `_patch_openclaw_config_for_mcp_bridge` 只添加 `blender-editor`
   （旧版本只支持 Blender），导致首次安装时 Maya/Max 未写入配置

3. 用户当前 `openclaw.json` 中 `servers` 只有 `blender-editor` + `unreal-editor`

**修复**（3 处）：

| 文件 | 修改 |
|------|------|
| `sidecar.py` | 新增 `SERVER_DCC_MAP` 显式映射表，优先精确匹配 |
| `dcc_installer.py` | patch 函数改为 4 个 DCC + 已存在时合并缺失 server |
| `openclaw.json` | 运行时补丁添加 `maya-primary` + `max-primary` |

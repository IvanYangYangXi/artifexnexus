## 三个核心 Bug 根因修复 (2026-05-22 最终轮)

- **修复**: `FindPlugin("ArtifexNexus")` → `FindPlugin("ArtifexNexusForUnreal")`，并增加 else 分支打印 Error 日志

### Bug 2: 标签栏图标不显示
- **根因**: 同 Bug 1（FindPlugin 名称错误导致 StyleSet 无 ContentRoot）
- **修复**: 同 Bug 1，外加 `ReloadTextureResources()` 确保渲染器加载纹理（参考 artclaw 模式）

### Bug 3: MCP Server 显示 Stopped（实际已在运行）
- **根因**: `_start_mcp_gateway()` 直接调用 `ue_mcp_server.start_mcp_server()`，跳过了 `init_unreal.start_mcp_server()` 中的 `subsystem.set_server_running(True)`。
  - 导致：Server 已启动但 C++ Subsystem 状态为 False → Panel UI 显示 "Stopped"
  - 恶性循环：Panel 打开时 `TryAutoStartServer()` 检测到端口被占用 → 无法启动 → 死锁
- **修复**: `_start_mcp_gateway` 步骤 3.5：调用 `subsystem.set_server_port(port)` + `subsystem.set_server_running(True)`

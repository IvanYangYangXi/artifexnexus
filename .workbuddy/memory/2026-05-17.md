## nexus-tools 路径架构重构：内嵌到 wrapper 包

### 背景
用户要求消除硬编码目录，让 nexus-tools 在 dev/绿色包/NSIS 三种启动方式下都能自动获取正确路径。

### 方案
采用方案 A：将 nexus-tools 内嵌到 wrapper 包 (`artifex-nexus-openclaw-wrapper`) 作为 package data，通过 `importlib.resources.files()` 定位。

### 架构决策
- nexus-tools 和 skill 是**逻辑平级**系统，不应放在 skill 包内 → 放在 wrapper 包（编排层）
- scanner 不感知路径来源，只接受 `bundled_nexus_tools_path` 参数
- 路径定位职责在 wrapper 层（`_rpc_helpers.py`），职责分离清晰
- `ARTIFEX_NEXUS_PROJECT_ROOT` 保留（dcc_installer.py 仍需要），Rust 侧零改动

### 改动文件（5 个）
1. **数据迁移**：`nexus-tools/` → `packages/.../openclaw_wrapper/_bundled_nexus_tools/`，删旧目录
2. **`_rpc_helpers.py`**：删除 `_get_project_root()`，新增 `_get_bundled_nexus_tools_path()` 用 `importlib.resources` 定位
3. **`scanner.py`**：`project_root` → `bundled_nexus_tools_path`
4. **`registry.py`**：透传参数改名
5. **`installer.py`**：透传参数改名 + publish 增加只读保护（`os.access(..., os.W_OK)`）

### 验证结果
- `importlib.resources.files('artifex_nexus.openclaw_wrapper')` → editable install 返回源码路径 ✅
- scanner 扫描 8 个工具（2 official + 6 marketplace）✅
- registry 过滤/搜索/get 全部正常 ✅
- wheel 构建（hatchling auto-discovery）20 个文件全量打包 ✅
- QA 审核通过（P0/P1/P2 无问题）

## nexus-tool 触发器三态 UX 重构

### 需求
1. "自动触发" → "启动触发"（renaming）
2. 启用/禁用与触发器状态**共同控制**，而非通过启用/禁用修改触发器状态
3. `is_enabled` 只控制触发器，**不影响手动运行**（运行按钮永远可用）
4. 无触发器工具不显示启用/禁用按钮

### 三态设计

| 状态 | 条件 | 徽章 | 按钮 |
|------|------|------|------|
| 无触发器 | triggers 为空 | 无 | 无（隐藏） |
| 启动触发 | triggers 非空 + is_enabled | 🟢 启动触发 | 「禁用触发」 |
| 禁用触发 | triggers 非空 + !is_enabled | 🔴 禁用触发 | 「启动触发」 |

### 改动文件（3 个）
1. **`registry.py`**：删除 `run_nexus_tool()` 的 `is_enabled` 门禁（手动运行不受限）
2. **`NexusToolList.tsx`**：新增 `triggerState()` 计算函数，重构徽章和按钮逻辑
3. **`ItemCard.tsx`**：`status` 属性改为可选，卡片/列表视图均加守卫渲染
4. QA 审核：无 P0/P1/P2 问题

## 详情面板触发状态联动更新

### 问题
卡片列表启用/禁用后，已打开的详情面板不会实时反映 `is_enabled` 变化。

### 方案
PreviewContext 的 data 中引入 `refreshKey` 作为"外部变动通知"。

### 改动（3 文件）
1. **NexusToolList.tsx**：`doAction` 成功后检查 preview 是否为同一工具 → 更新 `refreshKey: Date.now()`
2. **RightPanel.tsx**：提取 `refreshKey` → 透传给 ToolDetailPanel
3. **ToolDetailPanel.tsx**：新增 `refreshKey` prop → 加入 `loadDetail` 依赖数组 → useEffect 自动重载

### 数据流
```
卡片 [禁用触发] → doAction(disable) → loadTools()
                                    → setPreview({ ...data, refreshKey: now })
RightPanel → <ToolDetailPanel refreshKey={...} />
ToolDetailPanel → useEffect → loadDetail() → detail.is_enabled 更新 → TriggersTab 灰显
```
- QA 审核：无 P0/P1/P2 问题

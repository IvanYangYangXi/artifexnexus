### 安装后诊断 + Python 依赖版本固定 + pip 引导增强

**包体评估**：Lib_bundle 预下载 ~6.6 MB（websockets 116K + pydantic 461K + pydantic-core 2MB + cryptography 3.7MB + pyyaml 153KB + 依赖 876KB），使插件从 1.7MB → 8.3MB（+389%）。用户决定不预下载，走联网安装。

**版本固定（init_unreal.py）**：
```python
_REQUIRED_PACKAGES = [
    ("websockets", "websockets>=12.0,<13.0"),     # 纯 Python，12.x 稳定线
    ("pydantic", "pydantic>=2.10,<3.0"),           # 2.10+ 验证兼容 Python 3.11
    ("cryptography", "cryptography>=44.0,<49.0"),   # ABI 稳定，cffi 绑定兼容
]
_OPTIONAL_PACKAGES = [
    ("yaml", "PyYAML>=6.0.3,<7.0"),
]
```
从宽松 `>=` 改为有界区间 `>=min,<next-major`，避免自动升级到不兼容大版本。

### 依赖自动安装逻辑验证与 sys.path_importer_cache 假阴性修复（2026-05-24 13:41）

**问题**：用户发现 Lib 目录缺少 websockets + pydantic，但 UE 启动时日志显示 "Verified: websockets, Verified: pydantic"，怀疑自动安装逻辑有 bug。

**日志追踪结论**：自动安装逻辑**功能正确**，但有**缓存假阴性**导致不必要的后台触发。

**完整链路**（从 ue57_artifex_nexus.log 追踪）：
```
13:06:08.750  _add_lib_to_path()          ← Lib 不存在，加入 sys.path → importer_cache 标记为 None
13:06:08.837  _check_dependencies_fast()  → _ensure_lib_dir() 创建 Lib → _add_lib_to_path() NO-OP → 缓存过时
             → __import__("websockets")    ← 缓存仍为 None → 跳过 Lib → 找不到 → 假阴性 → 触发后台安装
13:06:08.840  _deferred_startup()          ← 启动后台线程
13:06:08.843  后台线程 _install_deps()     ← 检测到 websockets/pydantic 已可用（仅需装 cryptography+yaml）
              ← websockets/pydantic 来自引擎 Python site-packages（非 Lib）
13:06:16     cryptography 安装成功
13:06:20     PyYAML 安装成功, Verified: websockets, pydantic, cryptography
13:06:21     MCP Gateway started ✓
```

**根因**：`_add_lib_to_path()` 在 Lib 创建**前**被调用（_initialize:1081），Python 的 `sys.path_importer_cache` 将该路径标记为 `None`。`_check_dependencies_fast()` 虽然调用 `_ensure_lib_dir()` 创建了 Lib，但 `_add_lib_to_path()` 因路径已在 sys.path 中而 NO-OP，缓存未刷新 → `__import__` 跳过 Lib。

**修复（init_unreal.py）**：
1. `_add_lib_to_path()`：改为始终 remove+re-insert + `importlib.invalidate_caches()`，确保导入缓存被刷新
2. `_install_dependencies()`：简化离线 bundle 和最终验证阶段的缓存刷新逻辑，统一使用 `_add_lib_to_path()`
3. 消除 3 处重复的 remove+insert+invalidate_caches 代码

**修改文件**：
- `init_unreal.py`：`_add_lib_to_path()` 重构 + `_install_dependencies()` 简化
- Lib/ 目录：补全 websockets + pydantic

## 'bool' object is not callable — 根因修复 (16:35)

### 问题
MCP Server 启动持续报 `'bool' object is not callable`，DIAG 日志证明关键线索：
- `ue_mcp_server.start_mcp_server` 模块属性 → `type=function callable=True` ✓
- 但 `subsystem.is_server_running()` (init_unreal.py:1059) → TypeError ✗

### 根因：UE Python 绑定中 UPROPERTY 与 UFUNCTION 命名冲突

`ArtifexNexusSubsystem.h`:
```cpp
// 第 130 行 — UFUNCTION (方法)
UFUNCTION(BlueprintPure)
bool IsServerRunning() const { return bIsServerRunning; }

// 第 157-158 行 — UPROPERTY (属性)
UPROPERTY(BlueprintReadOnly)
bool bIsServerRunning = false;
```

UE Python 绑定生成器将 `bIsServerRunning` UPROPERTY → `subsystem.is_server_running`（去掉 `b` 前缀），返回 **bool 值**。这**覆盖**了同名 UFUNCTION `IsServerRunning()` 的方法绑定。

`subsystem.is_server_running()` → 尝试调 bool 值 → `'bool' object is not callable`。

artclaw 没有此问题——它**不暴露** `bIsServerRunning` UPROPERTY，只通过 Python 管理运行状态。

### 修复
**移除** `bIsServerRunning` 的 `UPROPERTY(BlueprintReadOnly)` 声明，改为普通成员变量：
```cpp
// 之前
UPROPERTY(BlueprintReadOnly, Category = "ArtifexNexus|MCP")
bool bIsServerRunning = false;

// 之后
bool bIsServerRunning = false;  // 只通过 UFUNCTION IsServerRunning() 暴露
```

### 修改文件
- `ArtifexNexusSubsystem.h`: 移除 bIsServerRunning 的 UPROPERTY
- `ArtifexNexusSubsystem.cpp`: 清理 DIAG 代码
- `init_unreal.py`: 清理 DIAG 代码
- 安装目录 + 源目录均已同步

### 教训
UE Python 绑定中，**不要同时暴露同名 UFUNCTION 和 UPROPERTY**（去掉 `b` 前缀后的名称会冲突）。UPROPERTY 优先于 UFUNCTION，导致方法调用变成属性访问。这是 UE PythonScriptPlugin 的已知行为。

## MCP 启动架构重构：消除竞争路径

### 根因
MCP Server 启动有两条竞争路径，导致 `bIsServerRunning` 状态不同步：
1. **Python 路径**：`_initialize()` → deferred tick → `_start_mcp_gateway()` → `ue_mcp_server.start_mcp_server()` (直接调用，绕过 subsystem 状态更新)
2. **C++ 路径**：`UArtifexNexusSubsystem::AutoStartMCPServer()` → `init_unreal.start_mcp_server()` (正确更新状态)

当路径1先启动 Server 但未更新状态 → 路径2看到端口被占用 → 放弃 → Panel 永久显示 Stopped

### 修复
- `_initialize()` 中 **移除** MCP 自动启动（不再通过 deferred tick 调用 `_start_mcp_gateway`）
- `_deferred_startup()` → `_schedule_mcp_start_on_game_thread()`：改用 `start_mcp_server()`（公共 API）替代 `_start_mcp_gateway()`
- MCP 启动由 `AutoStartMCPServer()` 单一入口负责
- Panel `TryAutoStartServer()` / `OnStartServer()` 也走同一个 `start_mcp_server()` API

## AttributeError 绕过 init_unreal 别名 (2026-05-23 23:03)

## 阶段一：安装程序 UI

- [ ] **NSIS 窗口正常弹出** — 双击安装包后 3 秒内出现安装向导
- [ ] **语言/界面文本正确** — 标题、按钮、许可协议文本无乱码
- [ ] **安装路径默认可接受** — 默认 `%LOCALAPPDATA%\Artifex Nexus`（或自定义路径有效）
- [ ] **自定义路径功能** — 点击"浏览"可选择其他目录
- [ ] **许可协议可查看** — 协议文本区域可滚动

## 阶段二：安装执行

- [ ] **安装进度条正常移动** — 不卡死、不跳变
- [ ] **安装过程中无错误弹窗** — 无 "DLL 缺失"、"路径不存在" 等错误
- [ ] **安装完成页显示正确** — 显示"安装完成"并有"运行 Artifex Nexus"复选框
- [ ] **安装时长合理** — 通常 10–30 秒

## 阶段三：安装后文件验证

- [ ] **安装目录存在且内容完整**

```
必含文件：
  - Artifex Nexus.exe          # 主程序
  - sidecar.py                 # Python sidecar
  - *.dll                      # Tauri/WebView2 依赖
```

- [ ] **桌面快捷方式生成** — 图标正确，路径指向安装目录
- [ ] **开始菜单条目生成** — 开始 → 所有应用 → Artifex Nexus

## 阶段四：首次启动

- [ ] **双击快捷方式正常启动** — 3–10 秒内出现应用窗口
- [ ] **无控制台窗口弹出** — 验证 `CREATE_NO_WINDOW (0x08000000)` 生效
- [ ] **WebView2 正常渲染** — 窗口内容不是白屏，显示前端 UI
- [ ] **窗口标题正确** — 显示 "Artifex Nexus"（非 "Tauri App" 或空）
- [ ] **窗口可正常拖拽、最小化、关闭**

## 阶段五：Sidecar 与运行时目录

- [ ] **`~/.artifexnexus/` 自动创建**

```
预期目录结构：
  %USERPROFILE%\.artifexnexus\
  ├── .openclaw\              # OpenClaw 隔离目录
  │   ├── openclaw.json       # 配置文件
  │   └── state\              # 状态目录
  └── logs\                   # 应用日志（如有）
```

- [ ] **`~/.artifexnexus/` 下无旧路径残留**
    - `~/.openclaw/` — 不应存在
    - `~/.artclaw/` — 不应存在

## 阶段六：Sidecar 通信

- [ ] **Python sidecar 进程静默运行** — 任务管理器中无可见 python 控制台窗口
- [ ] **前端显示连接状态** — UI 中显示正确的连接状态（OpenClaw 在线/离线）
- [ ] **环境变量注入正确**（可通过 Process Explorer 或日志验证）

| 环境变量 | 预期值 |
|----------|--------|
| `OPENCLAW_HOME` | `~/.artifexnexus/.openclaw/` |
| `OPENCLAW_STATE_DIR` | `~/.artifexnexus/.openclaw/state/` |
| `OPENCLAW_CONFIG_PATH` | `~/.artifexnexus/.openclaw/openclaw.json` |
| `OPENCLAW_NO_ONBOARD` | `1` |
| `ARTIFEX_NEXUS_HOME` | `~/.artifexnexus/` |

## 阶段七：系统集成

- [ ] **Tray 图标显示** — 系统托盘区出现 Artifex Nexus 图标（如已实现）
- [ ] **关闭窗口行为正确** — 点击 X 是最小化到托盘还是退出（按设计预期）
- [ ] **任务管理器进程名正确** — 显示为 `Artifex Nexus` 或 `artifex-nexus-desktop`

## 阶段八：卸载

- [ ] **控制面板可找到** — 程序列表中有 Artifex Nexus
- [ ] **卸载程序可正常启动** — 点击卸载后弹出确认/进度
- [ ] **安装目录被清除** — `%LOCALAPPDATA%\Artifex Nexus` 删除（或仅残留用户数据）
- [ ] **桌面快捷方式被移除**
- [ ] **开始菜单条目被移除**
- [ ] **`~/.artifexnexus/` 处理符合预期** — 确认是保留（保留用户数据）还是删除

## 阶段九：边界场景

- [ ] **重复安装** — 已安装状态下再次运行安装包，行为正确（覆盖/提示）
- [ ] **路径含空格** — 安装到 `C:\Program Files\Artifex Nexus` 等含空格路径
- [ ] **路径含中文** — 安装到 `D:\软件\Artifex Nexus` 等含中文路径
- [ ] **低权限用户** — 标准用户（非管理员）安装行为（NSIS 通常需要管理员权限）
- [ ] **磁盘空间不足** — 安装过程中磁盘满时的错误提示

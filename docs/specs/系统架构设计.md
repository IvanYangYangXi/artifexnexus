## 一、整体分层

```
┌──────────────────────────────────────────────────────────────┐
│                AI Agent 平台层                                │
│                OpenClaw（唯一首发，vendor 锁定版本）           │
│                安装路径: ~/.artifexnexus/.openclaw/           │
└────────────────────┬─────────────────────────────────────────┘
                     │
       ┌─────────────┴─────────────┐
       │ 上行: Gateway 私有 RPC      │ 下行: MCP JSON-RPC
       │                           │
┌──────▼───────────────────────────▼───────────────────────────┐
│         OpenClaw Gateway 转发层（vendor）                     │
│  ┌─────────────────────┐    ┌──────────────────────────┐     │
│  │ openclaw/uplink     │    │ openclaw/gateway-plugin  │     │
│  │ (Python, DCC 内)    │    │ (TS, Gateway 内)         │     │
│  └──────────┬──────────┘    └────────────┬─────────────┘     │
└─────────────┼────────────────────────────┼───────────────────┘
              │                            │
       ┌──────▼────────────────────────────▼────────────────┐
       │              DCC 插件层                              │
       │  ┌──────────────────────────────────────────────┐  │
       │  │ 插件框架: platform/core + platform/skill +    │  │
       │  │           platform/contracts                  │  │
       │  ├──────────────────────────────────────────────┤  │
       │  │ Skills（运行时安装到                          │  │
       │  │   ~/.artifexnexus/.openclaw/workspace/skills/）│  │
       │  └──────────────────────────────────────────────┘  │
       │            DCC 原生 API / SDK                        │
       └─────────────────────────────────────────────────────┘
```

## 二、四层 SDK / 契约

| 层 | 包 | 责任 | 详细 spec |
|----|----|----|---------|
| C — 共享核心 | `packages/platform/core` | bridge 协议、配置中心、记忆、健康检查、事件总线 | `[[sdk-core]]` |
| P — OpenClaw 适配 | `packages/adapters/openclaw` | OpenClaw uplink + gateway-plugin + vendor | `[[openclaw-wrapper]]` |
| D — DCC 适配 | `packages/dcc/<dcc>`（内含适配代码） | DCC 抽象，实现 `contracts.BaseDCCAdapter` | `[[sdk-dcc-interface]]` |
| S — Skill SDK | `packages/platform/skill` | `@tool` 装饰器、manifest、loader、hub、registry、installer | `[[skill-system]]` |

> 项目范围已收敛到单平台 OpenClaw（[[../decisions/0006-scope-converge-to-openclaw]]）；
> 不再保留通用 `<platform>` 抽象层。`adapters/openclaw/` 子目录仅作物理隔离用途。

`packages/platform/contracts/` 提供四层共用的契约（JSON Schema + pydantic 模型 + Python ABC + 自动生成的 TS 类型）。

## 三、与原项目的映射

| 原 artclaw_bridge | Artifex Nexus 新位置 |
|------------------|---------------------|
| `core/` | `packages/platform/core/` |
| `core/version_manager.py` 等 Skill 相关 | `packages/platform/skill/`（按职责拆 hub/registry/installer/...） |
| `core/interfaces/` 抽象基类 | `packages/platform/contracts/python/` |
| `cli/artclaw_bridge/` | `packages/platform/cli/`（命令统一改 `artifex skill *`） |
| `platforms/openclaw/*.py` | `packages/adapters/openclaw/uplink/` |
| `platforms/openclaw/gateway/` | `packages/adapters/openclaw/gateway-plugin/` |
| `subprojects/UEDAgentProj/Plugins/UEClawBridge/` | `packages/dcc/unreal/`（插件名 `ArtifexNexusForUnreal`，C++ 模块 `ArtifexNexus`） |
| 新增 | `packages/dcc/blender/`（addon 名 `Artifex Nexus`） |
| `tool-manager/`（Web） | `packages/apps/web/`（升级为 Artifex Nexus Web UI） |
| `~/.openclaw/` | `~/.artifexnexus/.openclaw/`（OpenClaw 整体隔离子目录） |
| `~/.artclaw/config.json` | `~/.artifexnexus/config/artifexnexus.json`（schema 在 contracts/schemas/） |
| `~/.openclaw/workspace/skills/` | `~/.artifexnexus/.openclaw/workspace/skills/`（保留 OpenClaw 平台规则） |

## 二、四层 SDK / 契约

| 层 | 包 | 责任 | 详细 spec |
|----|----|----|---------|
| C — 共享核心 | `packages/platform/core` | bridge 协议、配置中心、记忆、健康检查、事件总线 | `[[sdk-core]]` |
| P — OpenClaw 适配 | `packages/adapters/openclaw` | OpenClaw uplink + gateway-plugin + Python sidecar | `[[openclaw-wrapper]]` |
| D — DCC 适配 | `packages/dcc/<dcc>` + `packages/dcc/shared/` | DCC 抽象，实现 `contracts.BaseDCCAdapter`；共享 SDK 提供 MCPServer/SkillHub/装饰器基类 | `[[sdk-dcc-interface]]` |
| S — Skill SDK | `packages/platform/skill` | `@skill_tool` 装饰器、manifest、loader、hub、registry、installer | `[[skill-system]]` |

> 项目范围已收敛到单平台 OpenClaw（[[../decisions/0006-scope-converge-to-openclaw]]）；
> 不再保留通用 `<platform>` 抽象层。`adapters/openclaw/` 子目录仅作物理隔离用途。

`packages/platform/contracts/` 提供四层共用的契约（JSON Schema + pydantic 模型 + Python ABC + 自动生成的 TS 类型）。

## 三、DCC 插件架构

每个 DCC 插件由以下组件构成，共享 SDK 提供通用实现：

```
packages/dcc/<dcc>/
├── __init__.py
├── <dcc>_adapter.py        # DCC 特定适配器（继承 BaseDCCAdapter）
├── mcp_server.py            # MCP Server（复用共享 MCPServer 框架）
├── trigger_dispatcher.py    # 触发规则（复用共享 TriggerDispatcherBase）
├── <dcc>_ui.py              # DCC UI 集成（可选）
└── setup/                   # 安装部署脚本（可选）
```

**共享 SDK** (`packages/dcc/shared/artifex_nexus_sdk/`)：
| 模块 | 功能 |
|------|------|
| `base_adapter.py` | BaseDCCAdapter 抽象基类 |
| `mcp_server.py` | 基础 MCP Server 框架 |
| `skill_hub.py` | Skill 发现与执行中心（UE 有独立实现因需 `unreal.DirectoryWatcher`） |
| `skill_manifest.py` | Manifest 解析（全平台共用） |
| `decorator.py` | `@skill_tool` 装饰器唯一源 |
| `context.py` | 执行上下文（场景/选择/环境快照） |
| `event.py` | DCC 事件系统 |
| `logger.py` | 统一日志 |
| `params.py` | 工具参数验证 |
| `result.py` | 工具返回类型 |
| `trigger_dispatcher_base.py` | 触发规则基类 |

**已实现 DCC 插件**：

| DCC | 端口 | 语言 | 状态 | 关键文件 |
|-----|------|------|------|---------|
| Unreal Engine 5.7 | 18080 | C++ + Python | ✅ 完整 | `ArtifexNexusForUnreal_57/` |
| Blender 5.1 | 18083 | Python | ✅ 完整 | `blender/blender_addon/` |
| Maya 2023+ | 18081 | Python | 🔄 骨架 | `maya/` (adapter/UI/MCP/trigger) |
| 3ds Max 2024+ | 18082 | Python | 🔄 骨架 | `max/` (adapter/UI/MCP/trigger/startup) |

## 四、上行 / 下行链路

### 上行（聊天：用户→AI→DCC）

```
DCC 内 Chat Panel → uplink (WebSocket RPC) → OpenClaw Gateway → LLM
                                                ↓
                                          Gateway 解析工具调用
                                                ↓
                                          MCP JSON-RPC → DCC MCP Server
                                                ↓
                                          run_python 执行 @skill_tool 函数
```

### 下行（工具：AI→DCC）

```
OpenClaw Gateway (MCP Bridge Plugin)
  ├─ 维护到各 DCC MCP Server 的 WebSocket 连接
  ├─ 自动发现 DCC 工具（run_python）
  ├─ 工具命名：mcp_{server-name}_run_python
  │   例如：mcp_unreal-editor_run_python
  │        mcp_blender-editor_run_python
  │        mcp_maya-primary_run_python
  │        mcp_max-primary_run_python
  └─ 延迟发现 + 指数退避重连
```

## 五、SkillHub 全平台架构

```
packages/dcc/shared/artifex_nexus_sdk/skill_hub.py  ← 共享核心
packages/dcc/shared/artifex_nexus_sdk/skill_manifest.py ← 共享 manifest 解析
packages/dcc/unreal/.../skill_hub.py                 ← UE 独立实现（DirectoryWatcher）

启动流程：MCP Server 启动 → _init_skill_hub() → scan_and_register() → start_watching()
AI 调用：from artifex_nexus_sdk.skill_hub import get_skill_hub; hub.execute_skill("name", params)
```

```
01_marketplace → 市场 Skills（61 个）
02_user/       → 用户自定义
99_custom/     → 自定义覆盖
```

## 九、后续扩展方向（inbox → 设计阶段）

### 9.1 数据图形视图（P0）

**首期数据源**：CSV 文件导入。

数据流：
```
CSV → 解析（推断字段类型）→ ANDF → 视图渲染
                                      ↓
                                反向编辑 → ANDF Diff → 导出 CSV
```

**视图类型与能力**：

| 视图 | 字段配置 | 反向编辑 | 统计 |
|------|---------|---------|------|
| Table | 列自定义 | 单元格直编 | 列聚合 |
| Card | title/subtitle/image/desc/tags + 扩展 | 字段内联编辑 | - |
| List | primary/secondary + 扩展 | 字段内联编辑 | - |
| Tree | label/children（固定） | 重命名、拖拽 | - |
| Bar/Pie/Line/Scatter | xAxis/yAxis（固定） | 只读 | 图表自带 |

**字段类型**：string / number / boolean / datetime / url

**ANDF（Artifex Nexus Data Format）**：内部数据交换格式，列定义 + 行数组 + 视图配置。
详见 `docs/inbox/data-visualization-view.md`。

### 9.2 节点式工作流编辑器（P0）

**生命周期**：平台编码控制，WorkflowEngine 负责调度。

```
PENDING → RUNNING → DONE/BRANCHED/TERMINATED
              ↓
          WAITING（暂停等用户操作）
```

**右侧面板 Workflow 分页**（与预览面板并列）：
- 运行状态条（Running / Waiting / Done / Error）
- 当前阶段提示（当前执行节点名称 + 进度 N/M）
- 节点运行时 UI（User Choice 选项、Input Form 参数）
- 按钮控制（继续 / 暂停 / 终止）

**Gateway 参与范围**：仅对话类节点（Send to Chat / Get Chat Response / AI Analysis）。
工具/脚本/控制流节点不依赖 Gateway。

**AWF（Artifex Nexus Workflow Format）**：工作流序列化格式。
详见 `docs/inbox/workflow-node-editor.md`。

### 9.3 DCC 平台化 API（P2，最后做）

开放连接状态、Gateway Plugin、MCP Server、软件枚举等 API，
让用户通过 Chat + AI 引导即可接入任意新 DCC 软件。
详见 `docs/inbox/platform-extension-api.md`。
